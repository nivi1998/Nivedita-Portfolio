# Nivedita Kumari — Frontend Developer Portfolio

A responsive React + Vite portfolio website for job applications.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Framework preset: **Vite**.
4. Build command: `npm run build`
5. Output directory: `dist`
6. Deploy.

## Before publishing

- updated resume at `public/Nivedita-Kumari-Resume.pdf`.
- Update Email`nivedita.kumari@example.com` in `src/main.jsx` with your professional email.
- Replace placeholder project links with real live demos where available.
- Update the experience section with exact employer/date details from your current resume.
